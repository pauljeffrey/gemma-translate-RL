## 2. Prompt mixture (50 / 50)

`prompt.prompt_form_of(group_key|src_iso|tgt_iso)` (blake2b, salt `x2x-prompt-form-v1`): `explicit` = `Translate the text from {source} to {target}:  {text}`, `implicit` = `Translate the text to {target}:  {text}` (the en->X-compatible form, byte-identical to `format.build_example`: test). A deterministic function of the pair id, so both directions and all repetitions of a pair use one form, runs of windows are formed per form, and a window is never mixed. Measured on the pairs: 50.01 % explicit (3,342,169 of 6,683,317 in the first build); in the packed data of `sft_v2`: train **explicit 4,101,804 / implicit 4,103,832**, validation 28,204 / 27,696. `pairs_*.parquet` and the staged `sft_pairs_*.parquet` carry the `prompt_form` column; `packed/*/prompt_form.npy` (0 / 1) and `meta.json["prompt_mixture"]` the rule. Tests pin determinism, balance, and the identity with the en->X builder.

## 3. The SFT dataset to train on: `sft_v2` (mixture + NLLB-mined + 25 % replay)

* **Mined candidates** (`mined-sample`): per shard the top 20 % by margin score (P80), usual text filters (length, script, copy, length ratio), GlotLID of both sides, <= 8,000 per shard: 3,179,506 candidates from the 526 shards (33 languages), entering the selection as class `mined_nllb` (priority after human_curated, cap 40 % of a pair's draws; duplicates lose to direct pairs, win over pivot pairs). The class `mined_nllb` is new in `policy.CLASSES` (5 classes); same-language pairs are dropped everywhere.
* **Selection** (same UniMax, budget 8 M): 6,957,252 train + 83,214 validation pairs selected, **6,886,848 train + 82,180 validation after the text filters** (these feed the windows and the packed data); the staged export removes the rows of private-source repos: **6,842,249 train + 81,760 validation**. Composition of the 6,886,848: origin pivot_en 5,841,615 (84.8 %), mined_nllb 862,756 (12.5 %), direct 182,477 (2.6 %); religious_jw 4,459,872 (64.8 %, was 73.7 %), mixed 1,238,387, human_curated 244,630, synthetic_mt 81,203. 5,622 ordered directions have pairs, 4,104 have >= 1,000 pairs (was 3,854).
* **Replay** (`replay`, `pack --with-replay`): 1,033,766 windows of the en->X corpus (`windows_sft`, UniMax over the 77 languages, dropped 2,690 that match a held-out sentence) give 2 samples each (English -> X and X -> English), prompt form 50 / 50 from the same hash (the implicit en->X form is the original prompt); = **24.9 % of the samples**, validation 5,095 windows.
* **Packed (`sft_v2/packed`, same layout as `packed_fwd` + `src_iso_id.npy`, `prompt_form.npy`, per-sample `direction.npy` 0 / 1 / 2)**: train **8,205,636 samples, 413,103 packs of 4,096, 1,691,160,438 tokens (774,659,387 target), efficiency 0.9995**; validation 55,900 samples, 14,794,646 tokens; directions en2x 1,033,766 / x2en 1,033,766 / x2x 6,138,104; same tokenizer fingerprint as `packed_fwd`. X->Y directions: 5,622, median 1,267 samples = 274,452 tokens, 4,082 with >= 1,000 samples, none >= 10,000. Zstd copy for the bucket: `sft_v2/bucket_stage/afri2afri_packed_x2x_v2_with_replay.tar.zst` (+ sha256), uploaded to `remote:<S3_BUCKET>/afri2afri/packed_v2/`. The mixture-only, no-mined dataset of the first build is still in `/workspace/afri2afri/sft/packed` (train 6,244,748 samples, 1,328,607,081 tokens) and `sft_replay/packed` (with replay, 8,312,280 samples).

## 4. RL sources: web corpora streamed from the Hub

* **Scouting** (`afri2afri_scout_sources.py`, metadata only): for each of the 77 languages the folder of `HuggingFaceFW/fineweb-2` (76 of our languages), `cis-lmu/GlotCC-V1` (73), `HPLT/HPLT2.0_cleaned` (45), `wikimedia/wikipedia` 20231101 (37: afr amh bam dag ewe fon hau ibo kab kbp kik kin kon lin lug mlg nso nya orm pcm run sag sna som sot ssw swh tir tsn tso tum twi ven wol xho yor zul) and `allenai/c4` multilingual (13). 244 (language, source) jobs.
* **Fetch** (`pool-web`): **streamed with range reads (no download, no disk)**, <= 60,000 documents per job, stop at 3,000 windows per bin, same window rules as the English windows (whole sentences, AfroXLM-R token bins b64..b1024), GlotLID guard, dedupe, held out from the SFT pairs (any sentence shared with an SFT text drops the window) and from the benchmarks; real documents are preferred over pseudo-paragraphs when the cap of 1,500 windows per (language, bin) is applied. 22 min with 6 workers.
* **Result**: 509,493 prompts (was 411,814), **5,852 of 5,852 directions** (was 5,776; median 116 per direction, minimum 3), 280,031 distinct source windows (was 215,563), **74 % of the prompts come from real web documents** (fineweb-2 233,294 rows, HPLT 66,036, c4 65,176, Wikipedia 6,967, GlotCC 5,729) instead of 6 %; licences of the prompt rows: odc-by-1.0 298,470, cc-by-4.0 98,014, cc0-1.0 71,765, unknown 32,653, cc-by-sa-3.0 + GFDL 6,967, other 1,519. Dropped on the way: 29,737 windows sharing a sentence with SFT texts, 48,707 failing GlotLID, 4,057 basic / script, 3,057 duplicates, 1,096 benchmark; a re-check of 60,000 distinct prompt windows against the leak index (incl. the long-document documents) found 0 hits.
* **Pool sizes per language before -> after** (accepted windows over the four bins, capped at 1,500 per bin): `reports/afri2afri_2026-10-20/rl_pools_before_after.md` (all 77). Languages with fewer than 1,000 windows 21 -> 12; with fewer than 300 in some bin 45 -> 23. Largest gains: kea 8 -> 2,547, dyu 102 -> 2,781, ibb 150 -> 3,511, kon 139 -> 2,013, her 22 -> 1,063. **Still thin (no open source has more text): wes 54, ish 68, oke 139, dua 277, bas 474, bbj 526, urh 721, kri 728, yao 742, ndc 909, sid 931, shi 946.** Their fineweb-2 / GlotCC folders hold < 0.5 MB each.
* **Not fetched**: `uonlp/CulturaX` (gated "auto": needs the account to accept terms, which I do not do), `oscar-corpus/OSCAR-2301` (gated "manual"), `allenai/madlad-400` (open, ODC-By, but its layout needs a per-language probe and every language it covers is already saturated by the five sources; not worth the time before the thin-language question is answered), `masakhane/masakhanews` (AFL-3.0, ~16 languages, all already rich), AfriCorpus (no stable Hub id found). Wikipedia has no edition for most of the thin languages (kea her ish wes dua oke ...).

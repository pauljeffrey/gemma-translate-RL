# Source pool v3: benchmark-native documents, short items and relaxed licences (2026-10-20, evening)

Applies the owner decisions of the evening of 2026-10-20: licences relaxed (pure public research / education benchmark, nothing is trained on it; every record still carries its exact provenance, licence text / URL and an honest `licence_class`), the six English-length bins now include the short ones (b64, b256 + 512 / 1024 / 2048 / 4096), share-alike material is allowed in the core. Everything below was measured on the rental (`/workspace/sft_build/longdoc_bench/pool/`); tokens = Gemma-3 `tokenizer.json`, no BOS; all licence / terms pages were read on 2026-10-20. Nothing was pushed to the Hub or S3; the trainer, its watchers and the GPU were not touched (CPU, `nice -n 10`, at most 4 processes).

Fetcher: `gemma_mt/scripts/longdoc_fetch_sources.py` (new sub-commands `wmt_news`, `wmt_literary`, `ntrex128`, `flores_plus`, `glotstorybook_en`, `nalibali_en`, `mafand_en`, `unnews`, `simplewiki`, `wikijunior`, `wmt24pp-ids`; `stats` now also writes `docs_per_range`). Tests: `gemma_mt/tests/test_longdoc_sources.py` (**64 passed** on the laptop `.venv-comet` and **64 passed** on the rental with `python -m pytest`; synced to `/workspace/sft_build/longdoc_bench/code/`).

New pool mode `verbatim` (`Pool(verbatim=True, min_tokens=20, min_paragraphs=1)`): for curated benchmark text (WMT, NTREX, FLORES+, GlotStoryBook, MAFAND) the paragraphs are kept exactly as published (Unicode NFC + whitespace only), no prose heuristics, repeated paragraphs kept, one-paragraph documents allowed, floor 20 Gemma tokens (`n_gemma_tokens` still written), English check that also works for one-sentence items (`short_english_ok`). The other new sources (UN News, Simple Wikipedia, Wikijunior, Wikivoyage extension) use the normal prose cleaner with a lower token floor (100 / 150 / 100 / 400).

## 4. How the human references are attached (for the coordinator)

* NTREX-128: `ntrex128_lines.json[row id] = {"docid", "file": "NTREX-128/newstest2019-src.eng.txt", "lines": [start, end)}`; the same 0-based line range selects the sentences of every `newstest2019-ref.<lang>.txt` (24 African files available locally, `/workspace/sft_build/bench/test_sets/ntrex/NTREX-128/`). The pool text joins the segments of one WMT paragraph with a space (headline split off), so the document-level reference is built the same way from the reference lines (`extra.paragraph_segments` gives the segment ranges: segment id k = line `start + k - 1`).
* FLORES+: `flores_plus_ids.json[row id] = [[split, [ids]]]`; the reference row of language L is the row with the same `id` in `<split>/<L>.jsonl` (devtest copies in `bench/test_sets/flores_plus/devtest/`, dev in the HF cache). One reference sentence per id; the passage reference is the sentences joined by a space.
* WMT24 and WMT24 literary: `wmt24pp_ids.json[row id] = {"document_id", "segment_ids": {"en-sw_KE": [...], "en-sw_TZ": [...], "en-zu_ZA": [...]}}`; the post-edited human references are in HF `google/wmt24pp` (card licence apache-2.0; Deutsch et al. 2025, "WMT24++: Expanding the Language Coverage of WMT24 to 55 Languages & Dialects", https://arxiv.org/abs/2502.12404). All 25 WMT24 rows (17 news + 8 literary) have identical segment counts in the pool and in WMT24++ (checked), one segment = one paragraph.
* GlotStoryBook / Nal'ibali: `extra.parallel_id` ("asp_0001"): the rows of the same CSV with that `Parallel ID` and language, ordered by `Text Number`.
* MAFAND-MT: reference in `extra.parallel`.

## 5. Caveats common to the whole v3 pool

1. **Licence mix.** 6,012 share_alike (CC BY-SA 4.0), 729 `unclear` (WMT research-use terms 583 + 10, Nal'ibali 136), 714 permissive + 1 pd, 23,347 noncommercial (MAFAND CC BY-NC 4.0 21,781, UN News terms 1,500, GlotStoryBook NC 66). The dataset card should print this mix and list the source terms (quoted above). `unclear` and `noncommercial` rows can be filtered by `licence_class`.
2. **Contamination.** Almost everything here is a public benchmark (WMT, NTREX, FLORES+, MAFAND, GlotStoryBook) or Wikimedia text: the coordinator's contamination filter will flag much of it; flagged rows are still useful as "known benchmark" comparison items.
3. **WMT `url`/`date` are empty** (the data has neither); provenance is the test-set name + document id + outlet.
4. **Short items.** Single-sentence items (MAFAND, WMT22 en-liv) are b64 items; FLORES+ passages and WMT headlines+short bodies are b256 items.
5. The existing pool files and `POOL_STATS.json` of earlier versions were not modified (the stats file was regenerated for all files, previous copy `tmp/POOL_STATS_v2.json`).

## 6. Reproduce

```
cd /workspace/sft_build/longdoc_bench && . /workspace/sft_build/env.sh >/dev/null 2>&1
export PYTHONPATH=$PWD/code:/workspace/sft_build/pylibs HF_HOME=/workspace/sft_build/hf CUDA_VISIBLE_DEVICES=; PY=/workspace/venv_gemma/bin/python
S="nice -n 10 $PY code/scripts/longdoc_fetch_sources.py"
$S ntrex128         --out pool/ntrex128__share_alike.jsonl  --max-docs 500  --raw-dir raw/v3dl
$S wmt_news         --out pool/wmt_news__unclear.jsonl      --max-docs 5000 --raw-dir raw/v3dl --exclude-from pool/ntrex128__share_alike.jsonl     # 2020-2025
$S wmt_literary     --out pool/wmt_literary__unclear.jsonl --max-docs 100 --raw-dir raw/v3dl
$S wmt24pp-ids      --in pool/wmt_news__unclear.jsonl,pool/wmt_literary__unclear.jsonl --out pool/wmt24pp_ids.json
$S flores_plus      --out pool/flores_plus__share_alike.jsonl --max-docs 3000 --raw-dir raw/flores_local      # raw/flores_local/{dev,devtest}/eng_Latn.jsonl; without --raw-dir the Hub copy is used (token needed)
for c in permissive pd noncommercial; do $S glotstorybook_en --only $c --out pool/glotstorybook_en__$c.jsonl --max-docs 2000; done
$S nalibali_en      --out pool/nalibali_en__unclear.jsonl   --max-docs 500
$S mafand_en        --out pool/mafand_en__noncommercial.jsonl --max-docs 100000
$S unnews           --out pool/unnews__noncommercial.jsonl  --max-docs 1500        # 38 min at 1 request / s (2,127 requests, 87 stories without text rejected)
$S simplewiki       --out pool/simplewiki__share_alike.jsonl --max-docs 3000 --sample 0.03 --raw-dir raw/dumps          # 6 min
$S wikijunior       --out pool/wikijunior__share_alike.jsonl --max-docs 3000 --raw-dir raw/dumps                          # 90 s
$S wikivoyage       --out pool/wikivoyage_ext__share_alike.jsonl --max-docs 1700 --sample 0.5 --raw-dir raw/dumps --exclude-from pool/wikivoyage__share_alike.jsonl
$S stats --pool-dir pool --out pool/POOL_STATS.json --samples-dir pool/samples
cd code && $PY -m pytest -q tests/test_longdoc_sources.py          # 64 passed
```
`flores_plus_ids.json` and `ntrex128_lines.json` are written next to the `--out` file by the `flores_plus` / `ntrex128` runs. Politeness: User-Agent `SabiYarn-longdoc-benchmark/0.1 (research; contact <email>)`, robots.txt honoured by the `Http` class (UN News, GitHub raw / archive, Wikimedia dumps), at most 1 request / s per host; raw archives and dumps were deleted afterwards. Downloaded content was parsed as data only.

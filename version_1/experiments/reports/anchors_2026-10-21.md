Design rules: PENALTIES only (never a bonus: human references keep 44.5 % of the source's numbers+names, the model 73 %, so a recall reward would push towards copying). Every threshold is a quantile of HUMAN text (alpha 3 %); a detector is switched on for a language only where its cross-validated false-positive rate on human references is <= 4.5 % (target 3 %, the 2-fold estimate has ~1 point of noise) and, for the entity detector, where it flags >= 40 % of chunks paired with another source's translation. Languages without references (13 of the 45) borrow a proxy (`swc` -> `swh`, `wes` -> `pcm`) or the pooled prior (fitted on the weak languages, enabled only if its leave-one-out FP is small). Applied per chunk (entities, lexicon) or per sample (repetition, boilerplate, LID probability), subtracted from the reward and floored at the failure penalty (-2), own weight each, only for the content modes in `anchors_modes` (default consensus + blend) and never for the languages in `anchors_off_languages` (the CONTROL list, default empty).

### Detectors

* (a) entity/number preservation (chunk level). Numbers (digit strings, separators removed) and capitalised non-sentence-initial names (diacritic-folded, one edit allowed for names >= 5 letters; the definition of the RL-vs-SFT check). Deficit = max(0, t - recall) / t with t = the language's human 3 % quantile of the recall (the human p10 is 0 for names and for numbers in most of these languages, so it cannot be the threshold of a detector that must stay silent on good text; `p10` is stored next to `t`). Numbers and names are separate channels, each enabled per language.
* (b) repetition (sample level). Share of word 3/4/5-gram positions that repeat an earlier n-gram of the same output, against the human p97 for texts of that LENGTH (6 length buckets; never below the source's own repetition; for the long buckets never below the pooled p97 of REAL human documents: smol_doc / AfriScience papers repeat more than glued sentences). Linear from the threshold to a 30 % repeated share (the hard near-loop guard of the consensus languages fires at 4-gram 0.35, so the penalty is continuous with it). Also targets greedy loops of long inputs.
* (c) cross-prompt BOILERPLATE (sample level). Rolling per-language buffer of outputs of OTHER prompts (capacity 600 outputs, at most 4 per prompt, i.e. >= 150 prompts; max 250k hashes). Penalised: share of the output's word 5-grams (those not copied from the source) found in the outputs of >= 3 other prompts. Prompts whose English sources share a word 6-gram with the current one are not "other" (the same input sentence is translated the same way). No penalty until the language's buffer has >= 150 outputs from >= 30 prompts; thread-safe, in memory only (a restart warms up again); filled only by TRAINING calls (`group_size` > 1) AFTER all samples of the call were scored; the greedy evaluation neither reads nor writes it. Threshold: max(human p97, 3 %) -> full penalty at 40 %.
* (d) lexicon hook `lexicon_overlap(lang, src, mt)` (`anchors.lexicon_overlap`, delegates to R3's `rl/lexicon.py`; None when the language has no validated lexicon). Penalty below the human 3 % quantile of the overlap (`build_anchors_calibration.py --lexicon-dir` fits it); weight 0 = off.
* (e) minimum GlotLID probability per language (calibration `lid_prob.pmin` = p05 of the probability on human references whose label is accepted; weight 0 = off; needs `reward.lid_enabled`).

## 2. Measurements (all against HUMAN text unless stated)

Human data: FLORES+ dev (Hub) + smol_sent / ibom_mt / glot_story / salt / flores_moz / ntrex (thresholds only) + smol_doc and the AfriScience dev papers for the long buckets: 64 languages with references (<= 1,800 units each), 32 of the 45 weak ones. `scripts/eval_anchors.py`, raw numbers in `reports/anchors_2026-10-21/*.json`.

Entity is weak by measurement: in most weak languages the human references drop ALL numbers of a numbered sentence far more often than 3 % (sentences with numbers whose reference lacks one: ven 5 %, sag 6 %, vmw 10 %, mos 12 %, kam 16 %, kbp 15 %, seh 16 %, bam 9 %, ibb 74 %, dyu 62 %, efi 39 %; spelled-out or re-written numerals). A number penalty there would punish legitimate translations; it is enabled only where humans keep the numbers (fon 3 %, umb 1 %, kab 0 %). Many weak languages (nbl, tiv, kon, ach, nyn, kri, ndc: ~30 numbered sentences; kqn, lun, loz, kua, her: 0-2) have too few judged sentences.

|---|---|---|---|---|

### Detection of corruptions (human references corrupted; share of judged samples with a deficit > 0; mean penalty at the default weights)

| corruption | entity (3 weak languages with it) | repetition (32 weak) | boilerplate |
|---|---|---|---|
| another source's translation | **100 %** (deficit ~1, i.e. 0.5 per judged chunk) | 2 % | - |
| second half dropped | **59 %** (mean; minimum 43 %) | 1 % | - |
| last clause repeated 6x (greedy loop) | 1 % | **100 %** (penalty 0.997) | - |
| whole translation twice | 1 % | **100 %** (0.93-0.97) | - |
| a stock sentence appended to every output | - | - | **100 %** (penalty 0.82; 0.86 control) |
| another source's sentence appended | 1 % | 1 % | - |
| source copy | 0 % | 0 % | - |

The last two rows are NOT detected by design: source copy is the existing `copy_source` guard (and entities are copied, which raises recall); an appended unrelated sentence is the length window / `extra_output_penalty` / consensus. A clear violation costs 0.8-1.0 (loops, stock sentences) or 0.5 per chunk with missing numbers.

## 4. Run controls (`rl/run_controls.py`, `RLConfig.run_controls: true`)

* `<out_dir>/WINDDOWN` containing N (`echo 50 > runs/sci/WINDDOWN`; empty or invalid = 50): from the next step the learning rate decays LINEARLY to 0 over the next N steps (multiplier 1, 1-1/N, ... 1/N), then the run finishes normally: the last iteration evaluates, saves `last/`, pushes latest/best, writes `summary.json` (`"winddown": {started_at_step, steps, finished_at_step, completed}`); the file is renamed `WINDDOWN.done`. The start step is remembered in `WINDDOWN.state`, so a restart in the middle continues the wind-down; deleting `WINDDOWN` cancels it. If `steps` comes first the run just ends at `steps`.
* `<out_dir>/LR_SCALE` containing a float (`echo 0.5 > runs/sci/LR_SCALE`): multiplier on the learning rate, read every step (clamped to [0, 4], unreadable = 1.0, message printed once per distinct bad value). It multiplies with the warm-up, the KL guard's scale and the wind-down. Logged: `lr`, `lr_file_scale`, `winddown_factor`, `winddown_steps_left`.
* tested: parse, clamping, linear schedule, multiplication, cap by `steps`, restart in the middle, cancel, archive on completion, and an end-to-end CPU smoke (lr 0.5e-4 x (1, 0.8, ... 0.2), run ends at step 5 of 12, summary, `WINDDOWN.done`).

## 7. Risks and limits

1. Entity preservation is enabled for 4 of 45 weak languages only (measured: human translators drop or rewrite numbers there); the owner's "entity/number preservation" is therefore mostly a no-op for the weak set, and the science anchor (science prompts) carries the number constraint where it applies.
2. The boilerplate penalty is silent for ~40 steps after every (re)start and is not persisted; the buffer holds the policy of the last ~150 prompts per language (~140 steps), so it follows slowly. Sentence-level calibration (a buffer of 600 other references) is stricter than the training buffer (150 prompts); real documents and pseudo-documents show no excess.
3. Magnitudes: repetition + boilerplate can each take up to 1.0 and entity 0.5 per chunk, against a consensus reward range of [-2, 2.25]; the floor is the failure penalty. In languages where most outputs loop (ish, bin, bbj: 66-86 %) most of a group is penalised alike and the gradient comes from the less repetitive samples; watch `reward/anchors/penalty/<lang>` and `anchors/*/penalised_rate` in the first 100 steps.
4. Repetition thresholds for outputs of 400-2,000 words are extrapolated from ~450 human documents of 400-1,000 words (the 5th bucket reuses the 4th); the hard near-loop guard (4-gram 0.35) stays on top.
5. The greedy evaluation (`eval/reward`, selection by chrF++) is scored without the boilerplate term; `eval/reward` is therefore not exactly comparable with the training reward.
6. The 13-language weak monitor is a small sample of the weak set (60 sentences each, ~+-3 chrF++ noise per language); it detects collapses, not +0.5 changes.
7. `anchors_off_languages` is the A/B lever inside one run (e.g. three of the loop-prone languages); it only removes the penalties, the language still trains.
8. Paths in the yaml point at `/workspace/jobs/b2/...` (calibration, weak dev file); copy next to the other calibrations if that directory is cleaned. The code must be deployed to the run's source tree (`patch/new_and_changed_files.tar.gz`, or the two diffs for reward.py and train_rl.py; `train_rl.py.diff` also carries R1's one-line `run_smoke` scorer change).

# Laptop CPU speed of the 270M model (C1b report, saved 2026-10-24)

Model: final run checkpoint (`final2-step401`), converted on the box. Box CPU: Xeon Gold 6126 2.6 GHz (Skylake, AVX-512), pinned to exactly 4 cores, `nice`, 3 repetitions (ranges in `reports/data/cpu_speed_2026-10-23/*.csv`). The box was shared with the ablation and evaluations (1-3 busy neighbour cores); headline numbers below are solo runs; runs measured with several benchmarks in parallel are 7-17% too slow.

## Answer
Recommended laptop variant: llama.cpp GGUF Q8_0 (300 MB file on the box: `/workspace/jobs/c1b/models/gemma-science-translate-final2-step401-Q8_0.gguf`). 4 threads: 0.97 / 1.85 / 2.0 sentences/s at batch 1 / 8 / 32, i.e. 139 h per 1 M FLORES-length sentences at batch 32; chrF++ -0.02 against the GPU output [-0.22, +0.16]; RAM 0.4-1.2 GB. ESTIMATE for an 8 GB / 4-core laptop (0.5-1.0x of measured): 1-2 sentences/s, 8-17 min per 1,000 sentences, 6-12 days per 1 M sentences; fine for tens of thousands of sentences, not for millions. The GPU (vLLM) was about 100x faster. CTranslate2 int8 is faster (2.87 sent/s, 97 h per 1 M) but loses 1.7 chrF++ (Yoruba -4.8) and is not recommended.

## Speed (4 threads, solo)
| System | Batch | Sent/s | h per 1 M |
|---|---|---|---|
| Q8_0 | 1 / 8 / 32 | 0.97 / 1.85 / 2.00 | 285 / 150 / 139 |
| CT2 int8 | 1 / 8 / 32 | 0.77 / 1.95 / 2.87 | 363 / 142 / 97 |
First-token latency (batch 1): Q8_0 80 ms, CT2 int8 68 ms. Q4_K_M is no faster than Q8_0. Thread scaling (Q8_0 batch 8): 0.63 / 1.14 / 1.85 sent/s at 1 / 2 / 4 threads. An AVX2-only build matches the native build per core. Per language (Q8_0, batch 32): swh 2.46, hau 2.50, kin 2.11, amh 2.15, yor 1.58, tir 1.55 sent/s (cost follows output tokens: Yoruba and Tigrinya about 1.6x Swahili). Paragraphs (Q8_0, batch 8): 0.119 paragraphs/s (8.4 s each, about 430 per hour).

## Memory (peak RSS)
Q8_0 0.42 GB (batch 1) to 1.2 GB (batch 32); CT2 int8 1.0-1.4 GB (lean, no torch); CT2 fp32/hybrid 2.5-3.6 GB; NLLB-600M 2.2-3.2 GB; NLLB-3.3B 8.2-11 GB at batch 32 (does not fit an 8 GB laptop).

NLLB's lead is almost entirely on the Ethiopic-script languages (amh 37.6 vs 19.6, tir 25.1 vs 13.2); on swh, hau, yor, kin ours is 44.2 vs 43.1 (NLLB-600M beam 4) and 45.9 (NLLB-3.3B beam 4). On 490-token paragraphs NLLB writes only about 240 tokens (drops content): chrF++ 23.0 / 24.4 against 47 for ours.

## Caveats
Box CPU is probably faster per core than an older laptop i5 (M-series performance cores may be faster); DDR4 laptop bandwidth lowers decode speed; hybrid, fp32, Q4_K_M and PyTorch rows were measured with other jobs running or with one repetition; Hausa has 170 clean sentences instead of 200; the speed subsets are small; pcm is not in FLORES+, Tigrinya was used as the sixth language. No TranslatePsy data used.

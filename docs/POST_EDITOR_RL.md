## Why the first idea needs one change

"Reward = existing reward(output) + (reward(output) − reward(draft))": every sample of a GRPO group shares one draft, and advantages are standardised inside the group, so
`reward(draft)` is the same number for all members and cancels. The difference only steers training through what is *not* constant. The design below uses four such things:

1. the **unchanged draft is a member of every group** (identity member, like the greedy member), so each edit is measured against doing nothing;
2. a **dead zone** (|Δ| ≤ τ is QE noise, no reward and no penalty);
3. **regressions cost κ = 2×** what the same gain earns;
4. gains on a **defective draft** count up to 2× (the editor is paid most where something is missing).

## E1 context (why the reward must be careful)

E1 applied to every sentence: chrF++ −0.01 (FLORES+), −0.58 (NTREX), −0.93 (MAFAND), AfriCOMET about −0.01; it helps only on failed drafts (loops, unfinished, chrF++ < 10: +3.5 to +6.7 per sentence).
Half the sentences come back unchanged and the other half are edited with a net loss. So the reward has to (a) not pay for noise edits, (b) pay a lot for real repairs, (c) charge for breaking a good draft.

## Reward per sample

`q_d`, `q_e` = existing translation reward (QE ensemble AfriCOMET-QE-STL-1.1 + SSA-COMET-MTL, shaped, hard failures at −2) of the draft and of the edit. Failures of the edit (format, wrong language, loop, unfinished) keep −2.

| term | definition | default weight |
|---|---|---|
| gain | Δ = q_e − q_d. Δ in [−τ, τ] → 0. Δ > τ → (Δ − τ)·(1 + focus·severity). Δ < −τ → κ·(Δ + τ). clipped to ±2 | 1.0 (τ 0.02, κ 2, focus 1) |
| ref | only prompts with a human reference: tanh((chrF++(edit,ref) − chrF++(draft,ref)) / 15) | 0.6 |
| ledger, with reference | word alignment draft→edit. fixed = share of reference words the draft lacked that the edit now has; broke = share of reference words the draft had that the edit lost | +0.5·fixed − 1.0·broke |
| ledger, always | source anchors (numbers, names): recovered = in the edit and not in the draft; lost = in the draft and not in the edit; invented numbers = in the edit, not in source or draft | +0.3·recovered − 0.6·lost − 0.5·invented (cap 3) |
| repair | 4-gram repetition of draft minus edit, /0.35, clipped ±1 (removing a loop +, creating one −) | 0.4 |
| diacritics | reduction of the diacritic deficit (optional, from `rl/diacritics.py`) | 0.2 |
| ungrounded | ≥ 3 inserted words that are not in source, draft or reference, charged only when the QE gain is within the dead zone or negative (a real repair also inserts new words) | −0.3·share |
| churn | edit changed words but nothing improved (gain = ref = 0): −edit_rate | 0.15 |
| copy | edit == draft: 0 for a clean draft; −0.5·severity for a defective one | 0.5 |

`severity` (0..1): empty / unfinished / wrong language / loop → 1; otherwise the max of repetition share, 1.5×lost-anchor share, and how far q_d is below the language's low anchor.

Op accounting (`align_ops`): insertions, deletions, substitutions, and substitutions that are only tone/accent marks (dot-below stays a letter, as in `lexicon.fold`). Omissions of whole source chunks are already inside q_d / q_e (the translation reward's omitted/extra chunk failures), so no separate coverage term.

## Owner design additions (2026-11-03) and how they are implemented

**A. Reference and reference-free prompts (53 % / 47 %).** 4,102 of the 7,747 pool prompts carry a HUMAN reference translation; the other 3,645 are news prompts with no reference (reference-free, the rules as written above).
- Languages covered by reference-based AfriCOMET (the 42 `QE_VALIDATED` ones): reward = `refcomet` (tanh of the dead-zoned reference-COMET gain, weight 1.0, `refcomet_tau` 0.03, scale 0.05, regressions x2) + `ref` (chrF++ gain, weight 0.6) + word ledger + the QE gain at weight 0.35.
- Other languages with a reference: `ref` chrF++ gain at weight 1.0 + word ledger + QE gain at 0.35 (only where the QE shaper has a reliable calibration; otherwise the QE gain is 0 and the group takes weight 0.5 so it still teaches).
- Reference-free prompts: gain 1.0, ledger (anchors only), repair, ungrounded, churn.
- Group consensus is OFF in the editor (it rewards copying), NLLB pseudo-reference signal OFF, `reward.reference_weight` 0 (the reference enters through the editor reward only).

**B. Prompt rules.** Human references only (no NLLB / MT / Gemma targets; no non-commercial rows: `--no-nc` at selection; licences in the pool: CC-BY 2,313, share-alike 854, Apache 649, MIT 72, MPL 43, other 134, unspecified 36).
Every pair E1's SFT selection used (v2 ids) and everything in the protected index (benchmarks, R1-R3) is excluded. Unseen pairs and AfriScience-MT train beyond E1's picks are preferred; cap per language, all 81 RL languages covered (50-305 prompts each, median 80), religious-only languages do not dominate.
Drafts come from our own models (RL stage A greedy / T=0.7 / T=1.0 / beam-4, SFT final, A0) and MADLAD-400-3B; **no NLLB and no TranslatePsy draft is in any RL prompt** (filtered at `choose`). Draft mix 60 % below the language's median QE / 20 % clean (best own system, above-median QE) / 20 % other systems
(the owner asked for about 50/30/20; with that mix the mean draft chrF++ on reference prompts was 33.2 against the benchmark drafts' 30.6, with 60/20/20 and quantile matching it is 32.6, quantiles 15 / 21.5 / 30.6 / 40.5 / 50.7 at 10 / 25 / 50 / 75 / 90 %).
Quantile matching: on reference prompts the draft whose chrF++ vs the reference is nearest to a target drawn from N(30.6, 18) is picked inside each category (`--match-chrf 30.6`).

**C. Success is judged only on metrics that are not in the reward**: reference chrF++ and spBLEU (never in the reward for benchmark rows) on FLORES+ / NTREX / MAFAND / SmolSent / SALT / AfriScience test, edited vs draft, paired bootstrap, on greedy AND beam-4 drafts, plus strata, edit rate, loop rate, unchanged share.
SSA-COMET-MTL and AfriCOMET-QE are inside the QE ensemble that trains the editor, so on benchmark rows they are reported with that caveat (they are not independent evidence); reference AfriCOMET (STL-1.1) is also used in the reward on training reference prompts (never on benchmark rows).
Bar: significant chrF++ and AfriCOMET gain on FLORES+ and NTREX, no loss on MAFAND, and a gain on top of beam-4 drafts.

## Pre-launch check (measured, 1,587 held-out reference prompts, 9,522 E1 edits: identity + greedy + 4 samples at T=1)

Spearman with the human-reference chrF++ gain / the reference-COMET gain (per sample; within-group in brackets), QE ensemble scoring as in training:

| term | vs chrF++ gain | vs ref-COMET gain | decision |
|---|---:|---:|---|
| QE gain | 0.32 (0.30) | 0.62 (0.63) | keep |
| word ledger (source anchors, reference-free part) | 0.12 (0.13) | 0.16 (0.18) | keep |
| repair (loops) | 0.09 (0.03) | 0.04 (-0.03) | keep (sparse, 8 % non-zero, never negative overall) |
| ungrounded | 0.29 (0.27) | 0.56 (0.53) | keep |
| churn | 0.09 (0.14) | 0.08 (0.09) | keep |
| **copy** | **-0.04 (-0.04)** | **-0.08 (-0.09)** | **switched OFF** (rule: correlation <= 0). It paid -0.5 x severity to every unchanged defective draft; 47 % of the pool drafts count as defective and an unchanged draft beats the average T=1 edit, so the penalty pushed the wrong way |
| total, reference terms included | 0.80 | 0.89 | partly circular (it contains the ground truth) |
| **total as a reference-free prompt** | **0.40 (0.42)** | **0.65 (0.67)** | launch rule (>= 0.25) met; 81 languages: 94 % with a positive per-language correlation, median 0.33 |

The reference-COMET correlation is not independent of the QE ensemble (same encoder family); the chrF++ correlation is.
Noise: the QE gain of a one-word edit has a MAD-sigma of 0.096 reward units, and QE gains below about 0.10 have no positive association with the chrF++ or COMET gain (mean chrF++ gain -0.01 / -0.12 for gains in (0.02, 0.05] / (0.05, 0.10]; +1.3 / +3.4 / +9.5 for (0.1, 0.2] / (0.2, 0.5] / > 0.5), so **tau = 0.10** (was 0.02). The reference-COMET delta of one-word edits has a MAD-sigma of 0.033, so **refcomet_tau = 0.03** (was 0.01).
With copy off the identity member earns -0.04 on average (failed drafts only), greedy edits +0.04, T=1 samples -0.34 (reference-free scoring): the group will push the sampled edits towards the greedy ones.

## Copy-bias controls (all active together)

identity member in each group; dead zone; regression ×2; copy of a defective draft is negative; churn cost; KL to E1 (0.05, k3); drafts for the RL prompts are chosen so that they are not all good
(about 50% below the language's median QE, 30% clean drafts for "do no harm", 20% from other systems), and training pairs the editor saw in SFT are not used with their reference.

## Short-run plan (run under way)

- Start from E1 (the current editor). b64, group 16 = 1 identity + 1 greedy + 13 sampled + 1 beam-4 editor output; lr 1e-6; 100–150 steps; checkpoints every 20.
- Prompts: English sources + drafts from pairs the editor never trained on (about 8k, 81 languages, capped per language), no benchmark data (protected index). References only where they exist and were not in editor SFT.
- Checks BEFORE launch (CPU, about an hour): for E1 outputs on held-out pairs, the correlation of each term (and of the total) with the human-reference chrF++ gain; any term with correlation ≤ 0 is switched off.
- Evaluation: same as E1 (chrF++, spBLEU, AfriCOMET ref and QE, paired bootstrap vs the draft, strata) on greedy drafts AND on beam-4 drafts.
  Success: significantly positive chrF++ and AfriCOMET gain over the draft on FLORES+ and NTREX, no loss on MAFAND, and a gain on top of beam-4 drafts (the practical use). Beating beam-4's own gain over greedy (+1.56) is not required, but without a gain on top of beam-4 the editor is not worth shipping.
- Circularity: the reward uses QE models, so the success numbers are reference chrF++ and reference AfriCOMET only (benchmark references are never in the reward).

# Fluency penalty and Bible spelling term of the RL reward (section 34 of the reward walkthrough, added 2026-11-01)

Section 34 of `version_1/experiments/reports/rl_reward_explained_2026-10-19_v3.md`, which was appended on 2026-11-01 after that file was copied into `version_1/`. Sections 0 to 33 are unchanged and are not repeated here.

## 34. [v4, D-62, 2026-11-01] Fluency penalty (character 5-gram + word-order models) and the Bible spelling term: OFF by default

**What.** `gemma_mt/rl/fluency.py` scores a translation with a per-language CHARACTER 5-gram model (interpolated Witten-Bell, mean log-prob per character) and a WORD-ORDER score (mean over adjacent word pairs of log P(w | previous word) - log P(w); shuffled words score near 0). Both are z-scored against 300 held-out training sentences; `comb_z = (char_z + word_z) / sqrt(2)` (char_z alone for sentences with < 3 words). The models are stored as sorted hashed numpy arrays (one npz per language, `artifacts/fluency_models/`, built by `scripts/build_fluency_models.py`; no Python dicts at scoring time).

**Use in the reward** (`reward.fluency`, default False = bit-identical rewards; keys in `RewardConfig`): for every VALID scored sample of a language whose model is `usable` (`fluency_languages`: "usable" | "all" | [iso ...]) the reward is reduced by `fluency_penalty_weight * (floor - comb_z)`, clipped to [0, 1] reward units, never below the failure floor (-2). PENALTY ONLY, never a bonus (a bonus would reward repetitive, over-frequent text). `floor = min(fluency_z_floor (-2.0), p05 of comb_z on the language's HUMAN test text)` when `fluency_human_floor` (default): web held-out text scores higher than human references (Yoruba FLORES comb_z mean -1.95), so a fixed -2.0 would hit about half of the correct sentences; with the human p05 about 5 % of correct human sentences fall below the floor by construction. The text scored is the tag-stripped translation the reward already has. Logged (`metrics.jsonl`): `fluency/checked`, `fluency/comb_z_mean`, `fluency/penalty_rate`, `fluency/comb_z/<iso>`, `fluency/penalty_rate/<iso>`.

**Spelling term** (`reward.fluency_spelling_weight`, default 0 = off). Web and Wikipedia text writes diacritics inconsistently, so the general model does NOT police them (strip AUC 0.57 on FLORES, 23 languages with changed sentences). A CHAR model trained on BIBLE verses (consistent orthography) does for some languages: it is kept as `spelling_z` where its diacritic-stripping AUC on FLORES dev is >= 0.8: **yor 0.949, kik 0.822** (candidates not enabled: ewe 0.525, lin 0.455, wol 0.524; hau lug luo nya som swh twi: FLORES sentences carry no marks that could be stripped). Penalty = clip(weight * (spelling_floor - spelling_z), 0, 1); languages not on the list get none. The floor is the p05 of the held-out Bible verses unless that would penalise > 10 % of FLORES human sentences (it does for both: Bible style differs from FLORES), in which case the FLORES p05 is used (yor -6.24, kik -8.16). At that floor the term catches 27.5 % (yor) / 11.5 % (kik) of diacritic-stripped sentences and hits 5 % of correct human ones: a weak, low-cost signal, not a spelling checker; the calibrated diacritic penalty of D-31 stays in charge.

**Validity (FLORES+ dev human text, 45 languages; held-out web/Wikipedia text for the other 58).** Mean AUC human vs damaged, compact pruned models: shuffled words 0.878, garbled characters 0.994, text of another language 0.995 (all 45), diacritics stripped 0.571 (chance level: not policed), close sibling language 0.76 (10 languages with a sibling test; the cross-sibling `sibling_ratio` below is better). **96 of 103 languages are `usable`** (shuffle, garble, foreign AUC >= 0.8 each); unusable: dyu kam kea kik ssw umb vmw (word order 0.62-0.79). Training set per language (A translation targets / B human monolingual / C both, chosen on FLORES): B 78, C 16, A 9.

**Pruning.** Grams with count < 3 and contexts seen < 3 times, words < 2, bigrams < 2; where that lowered an AUC by more than 0.01 the language uses the next less pruned level ((2,2,1,1) for 21 languages). Max AUC drop against the unpruned validated model 0.0092 (mean 0.0023). Size: **165 MB** for 103 languages (mean 1.6 MB, largest 3.1 MB); loaded arrays 235 MB; load 0.7 s; scoring about 4,800 sentences/s (char + word) and 6,800/s (spelling) on one laptop core.

**Sibling ratio** (`FluencyScorer.sibling_ratio(iso, text)`: mean log-prob per character under `iso` minus the best under any sibling; siblings: zul/xho/nbl/nde, kin/run, swh/swc, bam/dyu and every language the fastText classifier confuses with share >= 5 %). Not in the reward yet. AUC own text vs the sibling's text, both scored as the claimed language: zul 0.987, xho 0.990, nbl 0.987, nde 0.995, kin/run 0.942, swh/swc 0.964, ssw 1.0, nya/tum 1.0 ... **bam/dyu 0.185 (inverted)**: the two models are not distinguishable and the data labelled dyu looks more like bam than the bam text does; dyu is also `unusable`. Do not use the ratio for that pair.

**Limits.** No adequacy (AfriCOMET-QE / consensus are the adequacy signals). The models are trained on web, Wikipedia, translation-target and (spelling only) Bible text: noisy, partly machine translated, diacritics inconsistent. Languages without FLORES are validated on held-out web text only (optimistic). Nothing has run in the RL trainer: `reward.fluency` needs `fluency_models_dir` on the training box (165 MB, `artifacts/` is not in git).

**Tests.** `tests/test_fluency_reward.py` (8): compact vs validated dict models on 200 sentences (tolerance 1e-3, measured 5e-15), clean/garbled/foreign/shuffled separation, flag off bit-identical (and weight 0 identical), penalty-only/clipped/never below -2, unusable languages untouched, spelling term only for listed languages, missing directory is an error, real artifacts if present.

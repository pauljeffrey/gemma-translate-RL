Until the audit finishes, M385 and A0-270 tables are labelled "unaudited" and no sentence of the form "clean" is written.

## 3. Metrics

All on NFC text, language tag stripped (`strip_iso_prefix` accepts both text and single-token tags), macro = equal weight per language.

| metric | definition | where |
|---|---|---|
| chrF++ | sacrebleu CHRF char 6, word order 2 | `gemma_mt.eval.metrics.chrf_pp` |
| spBLEU | sacrebleu BLEU `flores200` tokenizer (the script records the tokenizer; an offline `13a` fallback is refused by the bootstrap and must never be mixed in a table) | `metrics.spbleu` |
| AfriCOMET (reference) | `masakhane/africomet-stl-1.1`; only for languages with `africomet_status == verified` (42), the 12 `listed` shown separately and flagged; not for smol_doc/gatitos | `sft_benchmarks` (drop `--no-comet`) |
| AfriCOMET-QE (reference-free) | `masakhane/africomet-qe-stl-1.1`, for the 50 languages without a reference test where the language is covered | RL scorer, optional |
| finished rate | stop token within `max_new_tokens` | predictions `finished` |
| empty rate | empty after tag strip | scorer |
| LID pass | GlotLID top-1 in the language's accepted labels (`own`), and sibling-tolerant (`sib`); accepted labels from the registry (`calibration/lid_labels_v6.json`) | scorer (`--lid-model`) |
| copy rate | output is the English source (`rl.guards.is_copy_of_source`, Jaccard 0.9, sources of >= 4 words) | scorer |
| repetition rate | `is_repetitive` or `is_self_repetitive` | scorer |

AfriCOMET is the AfriMTE-trained reference model and has the length/entity bias studied in `africomet_bias_study.py`; it is reported next to chrF++, never as the only score.

## 4. Decodings

| decoding | scope | engine | note |
|---|---|---|---|
| **greedy** | all benchmarks, all languages, all models | vLLM (HF fallback allowed, recorded), `max_new_tokens` 768 | the headline and the only one comparable with the first paper's tables |
| **beam 4 + greedy fallback** | FLORES+ devtest, all languages (Tier 2); the 20-language study set (Tier 1) | HF `generate`, `num_beams=4`, default length penalty, fallback to the greedy output when the beam output is unfinished/repetitive/empty | the old best-quality setting (+0.68 chrF++ on the 270M RL model); beam search loops in `nus`/`kbp`: report the fallback count |
| **MBR-16** | the 20-language study set, 200 `no_pair` sentences each (n = 3,970, same sentences as `final_model_decoding_study_2026-10-21.md`) | vLLM `n=16`, temperature 0.7, `min_p` 0.05; pick the candidate with the highest mean chrF++ against the other 15 | the old finding: +0.83 chrF++ at 8 samples, **no spBLEU gain** (the utility is the metric); report spBLEU and AfriCOMET next to chrF++ and label the row "metric-matched" |

Documents: translated sentence by sentence (the b256 recipe); no document-level decoding is evaluated.

## 5. Breakdowns and groups (fixed before the 385M numbers exist)

`scripts/eval_385m_score.py --groups FILE` takes one grouping per run (macro only, seconds). Groupings to produce:

1. **old quality groups** (strong/medium/weak) for the 20 study languages: `reports/data/final_model_decoding_study/groups.json` (assigned in 2026-10 from the 270M, not from the new model).
2. **new resource tiers** from stage-B pack counts per language (head / mid / tail tertiles of the registry; counts from the shards' `iso_id`), plus the replay set (languages with < 2,000 old packs) as its own group.
3. **language family** (column `family` of `own_270m_per_language.csv` for the 45 old languages; registry families for the rest).
4. **script** (Latin, Arabic, Ge'ez, Tifinagh, Coptic, N'Ko-like).
5. **old-45 vs new-80** languages, and **RL-eligible (QE-validated, listed, consensus-only) vs SFT-only**.
6. benchmark domain (FLORES+ news/books/travel via `url` is not exported; skip).

Decision aid for the specialist-model discussion: the per-language table of M385 minus A0-270 (same clean data family) and the per-language gap to NLLB-3.3B where published, sorted; languages that are weak AND have a published NLLB reference gap are the specialist candidates.

## 6. Statistics

* Own-model comparisons (M385 vs A0-270, later RL vs SFT): **paired sentence-level bootstrap**, 1,000 resamples, equal language weight, same resample for both systems (`eval_385m_score.py --pair M385:A0`), 95% percentile interval; per language and macro (benchmark x subset x group). Only test-sentence variance; one training seed per system (stated).
* M385 vs old 270M models and vs published systems: **no significance claim**. The old models were trained on contaminated data and the published numbers come from other pipelines; report differences on `clean`/`no_pair` rows (old models) or on the languages and the `all` rows (published), as descriptive.
* Never average across different language sets: a macro is quoted for the set it is computed on, and `common` (the intersection of the listed systems) is the column used for comparisons.

## 11. Comparability caveats (short)

1. **Prompts and decoding differ**: our greedy/768-token chat-less prompt with a tag; NLLB beam search on raw text; AfriqueLLM 5-shot base models; AfroBench best-of-3 prompts. A difference of one or two chrF++ points across harnesses is not evidence.
2. **Old-model contamination**: the first-paper 270M saw 95% of FLORES+ devtest English; use only its `clean`/`no_pair` rows against the new model and say that those subsets are small (about 48 FLORES+ sentences per language in `clean`). The Efik/NLLB-language choices of the first run were made on devtest.
3. **Metric scale**: chrF++ vs chrF (AfriScience, no word n-grams), spBLEU vs BLEU tokenizers, AfriCOMET vs SSA-COMET (checkpoint and scale differ), MetricX/COMET-22 not convertible. Never put two metrics in one column.
4. **One reference**: chrF++ with a single reference favours the reference's wording; FLORES+ references differ from FLORES-200 in places (corrections); MBR on chrF++ raises chrF++ by construction.
5. **Language sets**: a macro over 19 languages is not a macro over 44; always print the language count and use `common`.
6. **Direction**: TranslatePsy and AfriNLLB-style aggregates average both directions; we evaluate English -> African only.
7. **Seeds**: one training seed per model; intervals cover test sentences only.
8. **Unaudited 385M data**: until step 1 is done, `clean` for M385 is a claim, not a measurement.

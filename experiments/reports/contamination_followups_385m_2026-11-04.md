## 4. (a) Paraphrase and near-duplicate contamination

What is NOT possible here: an embedding (LaBSE-type) or MT round-trip scan needs a GPU or a model download and the packed shards; not done. What was done instead is a lexical fuzzy scan of the benchmark rows against the reachable text (`a1_fuzzy_scan.py`; results `a_fuzzy_summary.csv`, `a_fuzzy_hits_per_benchmark_string.csv` (benchmark string ids and match classes, no training text), `a_fuzzy_meta.json`, `a1_scan.log`; the superseded first pass without the NLLB sub-directories and with a flawed containment rule is in `run1_a1_first_pass_without_nllb/`, do not use).

* Benchmarks: the eight audited test sets (FLORES+ devtest, NTREX, MAFAND, SmolSent, SALT, GlotStoryBook, IbomMT, FLORES-MOZ), English side (E) and reference side (R), strings of >= 4 normalised tokens (192,613 strings), taken from the stored predictions of the SFT run.
* Text scanned (both sides of every pair, every message of every instruction chat): 56,975,939 pair rows (A0 data 23.41 M, specialist 5.10 M, `extra` 0.67 M, `extra2k` 25.26 M incl. NLLB-mined 18.94 M, `extra2_hold` 2.54 M) and 4,277,612 instruction rows (`databox_backup/instr`, 84 parquet files). Coverage: all pair text that the clean rebuild and the stage-B intake produced before gating/packing, plus the raw instruction sets; not the packed shards, not the Tumbuka/Aya instruction sets beyond the files in `instr/`, not text only present in the bucket.
* Classes: run = the normalised benchmark string occurs as a contiguous token run in a training text; near = character-5-gram Jaccard >= 0.5; fuzzy = >= 80% of the benchmark's word trigrams in the text (no run, Jaccard < 0.5). Candidates need >= 25% of the benchmark's word trigrams; trigrams in > 40 benchmark strings are ignored (recall loss for strings made of common trigrams).

* **No benchmark string of 8 or more tokens occurs as a run** in any reachable text (consistent with CONT).
* The contiguous-run hits are all 4-7 token strings (164 / 102 / 63 / 41 distinct strings of 4 / 5 / 6 / 7 tokens), e.g. generic phrases ("what are its effects", "african cup of nations", "everyone has the right to education") or MAFAND headline fragments inside longer sentences. This is a hole the audit could not see by construction: both the scorer's contiguous-run rule (`contamination.py`: run detection starts from 8-gram candidates) and the intake filter (`decon.py` R2: protected sentences of >= 8 tokens only) test strings of 3-7 tokens only for equality with a whole sentence. So "no benchmark sentence of 3 or more words is in the text" (CT1) holds for whole sentences; phrases of 4-7 tokens inside longer text are present (MAFAND 134 of 17,428 English strings, 0.8%; GlotStory 30 of 898; NTREX 18 of 1,973; SALT 12 of 498; FLORES+ devtest, SmolSent, IbomMT, FLORES-MOZ 0). The reference side has the same pattern (MAFAND 96, NTREX 72).
* Near-duplicates (8+ tokens, English side, Jaccard >= 0.5 with some text): 263 (string, benchmark) cases (MAFAND 184, SALT 27, NTREX 19, GlotStory 15, SmolSent 6, FLORES+ devtest 4). Strength: MAFAND 8 at >= 0.8, 18 at 0.7-0.8, 48 at 0.6-0.7, 110 at 0.5-0.6; NTREX 1 / 0 / 3 / 15; SALT 1 / 1 / 7 / 18; GlotStory 0 / 3 / 5 / 7; SmolSent 0 / 0 / 2 / 4; FLORES+ devtest 4 at 0.5-0.6. 32 English strings reach 0.7: texts in `data/` (12), `extra2k/nllb` (11), `igbo_bundles` (3), `swh_rogendo`, `dochplt`, `autshumato` (2 each). NLLB-mined text contributes the largest number of near hits (360 near hits in `nllb/`, 297 in `data/`, 91 in `igbo_bundles`; counts are per best match per benchmark string, `how` = near). These are likely the same sentence with changed punctuation, number or wording; the n_near count of CONT (8-gram >= 50%) found 0 on the packed samples; my reading (inference, not tested) is that these overlaps are character-level and below the 8-gram threshold, or sit in pre-gate/unused text. They are NOT proof of leakage: the hits include pre-gate text and the held-out `extra2_hold`, and the match text is not stored. They are the candidate list for a per-string review (`sid` column = index into the benchmark string list built by `a1_fuzzy_scan.build()`).
* FLORES+ devtest, the headline benchmark: 0 runs, 4 of 1,012 English strings with Jaccard 0.5-0.6; reference side 1 run (a 4-7 token fragment), 3 near.
* Impact on the paper: the clean-subset convention (CT1/CT2) stays; add the sentence "phrases of 4-7 tokens of 134 MAFAND, 18 NTREX, 12 SALT and 30 GlotStory English strings occur inside longer training texts of the reachable pair/instruction data; whole-sentence leakage and 8-gram sharing were audited separately (CONT)". Whether these inflate scores is not measured.
